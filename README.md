# Test Repository

A modular repository containing AI agent engineering protocols, curated agent skills, system prompts, and automated workflows.

---

## 📁 Repository Structure

```text
.
├── agents/          # Core behavioral & engineering protocols (AGENTS.md)
├── prompts/         # Diagnostic, auditing, and maintenance prompt templates
├── skills/          # Modular agent skills, references, and tool scripts
│   └── apex-ui-ux/  # Elite UI/UX design & frontend engineering skill
└── workflows/       # Automated workflows and orchestration pipelines
```

---

## 🚀 Components

### 🧠 Agents (`agents/`)
- **[`AGENTS.md`](agents/AGENTS.md)**: Lean Senior Engineering Protocol synthesizing industry guidelines (Andrej Karpathy Guidelines, Ponytail, Caveman, Matt Pocock, GSD, Cloudflare Security Audit, and Strix Pentesting) for pragmatic, autonomous execution with high signal and minimal boilerplate.

### ⚡ Skills (`skills/`)
- **[`apex-ui-ux`](skills/apex-ui-ux/)**: Advanced UI/UX design engineering skill equipped with:
  - Design tokens, effects, and taste presets.
  - Cross-platform guidelines and view transition recipes.
  - Automated audit and snapshot scripts (`audit-ui.mjs`, `snapshot.mjs`).

### 📋 Prompts (`prompts/`)
Curated prompt templates for system diagnostics, optimization, and automation:
- **`disk-space-detective.md`**: Intelligent disk usage analysis and safe space recovery.
- **`email-cleanup-organizer.md`**: Efficient email decluttering and categorization.
- **`pc-health-audit.md`**: System health, thermal, and performance inspection.
- **`wifi-diagnostics.md`**: Network stability, signal, and latency troubleshooting.
- **`windows-debloat-safe.md`**: Safe Windows debloating and telemetry minimization.

### 🔄 Workflows (`workflows/`)
- Staging directory for multi-step agent workflows and continuous automation scripts.

---

## 🛠️ Usage

Integrate this repository with your AI coding assistant (e.g., Antigravity, Claude Code, Cursor):
- Reference [`agents/AGENTS.md`](agents/AGENTS.md) as the root instruction or system prompt.
- Utilize the modular skills in [`skills/`](skills/) for specialized tasks.
- Execute diagnostic routines using the templates in [`prompts/`](prompts/).
