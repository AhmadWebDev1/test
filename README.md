# fix-with-ai

A modular, open-source collection of **evidence-based diagnostic prompts**, **AI agent protocols**, **curated skills**, and **automated workflows** — built to troubleshoot real-world tech problems and streamline software engineering safely.

> Designed to work seamlessly with **Antigravity**, **Claude Code**, **OpenCode**, **Cursor**, and any agent that reads Markdown instructions.

## Repository Structure

```text
fix-with-ai/
├── agents/          # Core behavioral & engineering protocols (AGENTS.md)
├── prompts/         # Safe, evidence-based diagnostic & maintenance prompts
├── skills/          # Modular agent skills, references, and audit scripts
│   └── apex-ui-ux/  # UI/UX design & frontend engineering skill
└── workflows/       # Multi-step automated workflows & pipelines
```

## Diagnostic & Maintenance Prompts (`prompts/`)

Every prompt follows a strict **read-only diagnosis first -> evidence-based plan -> reversible change with approval** rule.

| Prompt | What It Solves | Direct Link |
| :--- | :--- | :--- |
| **Wi-Fi Diagnostics** | Isolate slow speed, high latency, packet loss, and router interference | [wifi-diagnostics.md](https://www.google.com/search?q=prompts/wifi-diagnostics.md) |
| **PC Health Audit** | Find what is actually causing slowdowns, loud fans, or high RAM/CPU usage | [pc-health-audit.md](https://www.google.com/search?q=prompts/pc-health-audit.md) |
| **Disk Space Detective** | Map storage hogs safely and classify cleanup items before deleting anything | [disk-space-detective.md](https://www.google.com/search?q=prompts/disk-space-detective.md) |

## Quick Start

1. **Run a diagnostic prompt:** Open any file in [prompts/](https://www.google.com/search?q=prompts/), click **Raw**, copy the content, and paste it into your AI agent or terminal assistant.
2. **Adopt the agent protocol:** Copy [agents/AGENTS.md](https://www.google.com/search?q=agents/AGENTS.md) into the root of your project as `AGENTS.md`.
3. **Install a skill:** Copy any folder from [skills/](https://www.google.com/search?q=skills/) into your agent's skills directory (e.g. `.agents/skills/`).
